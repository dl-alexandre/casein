surfaces, not the product

Ten visualizations of the same underlying system: a control plane for durable AI-assisted software execution across isolated workspaces. The product is the orchestration runtime — these surfaces are just windows into it.

What this is

Workspaces  ·  isolated execution environments
Agents  ·  leased workers polling assignments
Assignments  ·  durable units of work
Leases  ·  ownership tokens, time-bounded
Policy  ·  admission, allowlist + workspace mode
Audit  ·  replay-safe event stream
Mode  ·  safe / review / write per workspace

What this is not

a code editor
an LSP host
a terminal multiplexer  tmux is an impl detail
an agent framework  agents are clients of the contract
a prettier Cursor / Codex / Claude Code

Analogy: JX = control plane · DevIDE = node runtime · workspace = pod · agent = container · lease = scheduler ownership · audit = event log · policy gate = admission controller.
