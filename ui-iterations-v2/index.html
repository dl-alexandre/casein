DevIDE · UI studies (humble version)

Just a terminal,
attached to a workspace.

The actual app: a browser terminal wired to a tmux session in a remote workspace, with a policy gate quietly refusing argv that isn't allowlisted. Audit log lives behind a drawer.

# what the app does
1. you pick a workspace
2. a terminal in your browser attaches to its tmux session
3. you type commands · the policy gate decides allow/deny before exec
4. denials and runs are logged · you can pull up the audit when you care

# what the app does NOT do
no editor · no LSP · no file tree · no fleet dashboard · no mission ops
