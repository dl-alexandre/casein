DevIDE · v3 · terminal-native remote workspace operating environment

Same UI.
Three backends.

A portable terminal client. Attach it to your laptop, a remote workstation, or a governed fleet. The interface stays the same. The depth surfaces only when you reach for it.

# the visible story
attach to a workspace from anywhere · the environment persists · execution is governed · operational state is visible

# the hidden depth
leases · replay · admission policy · audit · assignment queue — all reachable, none in your face
